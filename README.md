**#Ant Simulation in Unity (C++)**

This project is an interactive ant colony simulation developed in Unity using C++. Inspired by Sebastian Lague’s *Ant and Slime Simulations* (https://www.youtube.com/watch?v=X-iSQQgOd1A&t=96s), it visually demonstrates emergent complex behaviors of ants through pheromone-based navigation.

**##Features**

- Pheromone Trails: Ants deposit and follow pheromone paths using a pheromone map, allowing them to sense nearby food sources and their home colony.

- Emergent Behaviors: Using a simple pheromone approach, ants exhibit realistic colony behaviors, dynamically developing efficient paths to food while retaining exploration characteristics to minimize path length. Additionally, the simulation replicates the phenomenon known as the "Circle of Death," observed in real ant behavior.

- Interactive Environments: Click anywhere on the map to generate food sources for the ants, enabling dynamic interaction and observation of emergent behaviors.
